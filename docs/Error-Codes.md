# Коды ошибок KSL

У каждой ошибки и предупреждения в консоли есть код вида `0583c`: четыре цифры и буква.

- **Буква** означает категорию (таблица ниже).
- **Цифры** намеренно разбросаны, а не идут подряд, чтобы код легко узнавался и искался. Каждый номер встречается один раз.

В консоли код стоит в квадратных скобках сразу после имени скрипта:

```
[economy/shop] [6156a] ❌ Ошибка компиляции ...
```

Расшифровка кода прямо в игре или консоли: `/ksl error 6156a`. Последняя ошибка с кодом: `/ksl errors`.

## Категории

| Буква | Категория | Количество |
|---|---|---|
| `a` | Загрузка и выполнение скриптов | 11 |
| `b` | База данных и хранилище | 10 |
| `c` | Команды и события | 6 |
| `d` | Эффекты и частицы | 5 |
| `e` | Мобы и сущности | 11 |
| `f` | GUI-меню | 6 |
| `g` | Интеграции, хуки и Discord | 6 |
| `h` | Аддоны и API | 11 |
| `i` | Конфигурация и файлы | 5 |
| `j` | Планировщик и задачи | 2 |
| `k` | Плейсхолдеры и тексты | 5 |
| `l` | Система и остановка плагина | 2 |

## a — Загрузка и выполнение скриптов

| Код | Что случилось | Что делать |
|---|---|---|
| `0983a` | Скрипт загружается слишком долго | В top-level коде есть тяжёлые операции (сеть, диск, БД). Вынеси их в runAsync или onEvent. |
| `1867a` | Не всё удалось убрать при выгрузке скрипта | Часть ресурсов скрипта (задачи, слушатели, команды) могла остаться. Если повторяется, перезапусти сервер. |
| `2413a` | Предупреждение компилятора | Скрипт загружен, но компилятор нашёл подозрительное место. Исправь, чтобы не было неожиданностей. |
| `3297a` | Имя скрипта выходит за пределы scripts/ | Используй только путь внутри папки scripts/, без '..'. |
| `4438a` | Автоперезагрузка скриптов не запущена | Проверь права на папку scripts/ и лимит наблюдателей файловой системы. Скрипты по-прежнему перезагружаются командой /ksl reload. |
| `4726a` | Запрещённый вызов (sandbox) | Скрипт использует паттерн из списка sandbox. Убери вызов или выключи sandbox в config.yml, если скрипту можно доверять. |
| `5610a` | Циклическая зависимость @requires | Скрипты ссылаются друг на друга по кругу. Разорви цикл: вынеси общий код в третий скрипт. |
| `6156a` | Ошибка компиляции скрипта | Открой сообщение ниже: там строка и причина. Проверь скрипт командой /ksl validate. |
| `7040a` | Скрипт не найден | Проверь имя: оно считается от папки scripts/ без .kts, например economy/shop. Список: /ksl reload и Tab. |
| `8470a` | Исключение при выполнении скрипта | Ошибка случилась в коде скрипта. В логе указана строка .kts. Исправь код и сделай /ksl reload <скрипт>. |
| `9353a` | @requires указывает на несуществующий скрипт | Проверь имя в строке // @requires: оно должно совпадать с идентификатором скрипта (путь без .kts). |

## b — База данных и хранилище

| Код | Что случилось | Что делать |
|---|---|---|
| `0437b` | Не удалось прочитать persist-значение | Проверь соединение с БД (/ksl doctor). Скрипт получит значение по умолчанию. |
| `1321b` | Служебные таблицы KSL недоступны | Миграции не применились. Проверь права пользователя БД на CREATE TABLE и перезапусти сервер. |
| `2750b` | Операция с table() не удалась | Проверь соединение с БД (/ksl doctor). Операция не выполнена, остальные скрипты не затронуты. |
| `3634b` | increment() не удался | По указанному ключу лежит не число или БД недоступна. Проверь значение и /ksl doctor. |
| `4180b` | Часть записей не сохранилась при остановке | Очередь записи в БД не успела опустеть. Не убивай сервер принудительно, дай ему остановиться штатно. |
| `5064b` | SQL-запрос из скрипта не удался | Проверь текст запроса: он должен быть переносимым между SQLite и MySQL/MariaDB (без PRAGMA и AUTOINCREMENT). |
| `6494b` | Не удалось сохранить persist-значение | Значение осталось только в памяти до рестарта. Проверь соединение с БД (/ksl doctor). |
| `7377b` | Ключ длиннее 190 символов | MySQL/MariaDB не принимает такие ключи. Сократи ключ в ksl.db и повтори /ksl dbmigrate confirm. |
| `7924b` | Не удалось подключиться к базе данных | Проверь database.* в config.yml, что сервер MySQL/MariaDB запущен, база создана и у пользователя есть права. См. docs/Database-Guide.md. |
| `8807b` | Тип значения не поддерживается хранилищем | Сохраняй только String, Int, Long, Double, Boolean или null. Списки и объекты сериализуй в строку сам. |

## e — Мобы и сущности

| Код | Что случилось | Что делать |
|---|---|---|
| `0228e` | У локации нет мира | Мир не загружен или локация создана без мира. Проверь loc(...) на null. |
| `1112e` | В equip() указан не предмет | Проверь название материала, например DIAMOND_SWORD. |
| `2542e` | Неизвестный ключ шаблона моба | Допустимые ключи перечислены в сообщении; свои можно добавить через api.registerEntityAttribute. |
| `3426e` | Исключение в обработчике моба | Ошибка в onTick/onDeath/onDamaged/onAttack. Остальное поведение моба продолжает работать. |
| `3972e` | Сущность не является живым мобом | spawnCustomEntity создаёт только LivingEntity (ZOMBIE, COW...). Предметы и снаряды так не спавнятся. |
| `4855e` | Неизвестный слот в equip() | Доступны HAND, OFFHAND, HELMET, CHESTPLATE, LEGGINGS, BOOTS. |
| `6285e` | HP вне допустимого диапазона | HP должен быть больше 0 и не больше 1024. Значение проигнорировано. |
| `7169e` | onTick моба отключён после ошибок | Обработчик onTick упал 5 раз подряд и остановлен. Исправь код и пересоздай моба. |
| `7715e` | Неизвестный TYPE в шаблоне моба | Используй имя из EntityType, например ZOMBIE. Вместо него заспавнен ZOMBIE. |
| `8599e` | Не удалось применить атрибут моба | Проверь значение и что у этого моба есть такой атрибут (у коровы нет attack_damage). |
| `9482e` | Не удалось убрать моба при выгрузке | Моб мог остаться в мире, он будет удалён при следующей загрузке чанка. |

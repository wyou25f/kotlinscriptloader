# Коды ошибок KSL

В каталоге **267 кодов причин**. Код состоит из четырёх цифр и буквы категории, например `6156a`.

- Цифры уникальны и разделены не менее чем 20 позициями, чтобы коды не путались.
- Последняя буква указывает на подсистему.
- У каждого кода есть понятное название и следующий шаг для исправления.

В игре или консоли:

- `/ksl error 6156a` — объяснение конкретного кода.
- `/ksl errors` — последняя зарегистрированная ошибка и число ошибок за запуск.
- `/ksl errors list` — весь каталог.
- `/ksl errors list b` — ошибки базы данных.
- `/ksl errors list b 2` — вторая страница категории.

В консоли код ставится рядом с ошибкой:

```text
[economy/shop] [6156a] Ошибка компиляции скрипта
```

KSL OFFLINE LIBRARY — FOUR BOOK EDITION
========================================

Откройте index.html в современном браузере. Читалка работает полностью локально:
никакого сервера, Node.js или интернет-соединения не требуется.

Файлы рядом:
- index.html       интерфейс и семантическая разметка;
- style.css        оформление, responsive layout и режим печати;
- app.js           поиск, навигация, оглавление и подсветка кода;
- books-data.js    полные тексты четырёх книг, собранные из docs/*.md.

Возможности:
- четыре книги и главы;
- полнотекстовый поиск (Ctrl+K);
- оглавление выбранной главы;
- предыдущая/следующая глава;
- копирование блоков кода;
- печать главы и сохранение в PDF средствами браузера;
- мобильная навигация;
- отсутствие внешних CDN и сетевых запросов.

Источники истины — четыре Markdown-файла в docs/:
01-scripts.md
02-addons.md
03-data-and-databases.md
04-cookbook.md

После изменения книг обновите books-data.js тем же содержимым. Не редактируйте
только books-data.js: изменения должны сначала попасть в Markdown-источник.

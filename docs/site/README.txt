KSL OFFLINE LIBRARY
===================

Как пользоваться:

1. Скачайте папку docs/site целиком (или весь репозиторий).
2. Сохраните рядом все файлы: index.html, style.css, app.js и books-data.js.
3. Откройте index.html двойным щелчком в браузере.

Никакой установки, локального сервера, Node.js или интернета не требуется.
Тексты четырёх книг встроены в books-data.js.

Клавиши:
- Ctrl+K — поиск по всем книгам.
- Esc — закрыть поиск или боковое меню.
- Стрелки влево/вправо — предыдущая/следующая глава.
- Кнопка «Печать» — печать главы или сохранение в PDF через диалог браузера.

Исходные книги находятся в папке docs/:
01-scripts.md
02-addons.md
03-data-and-databases.md
04-cookbook.md
